영양성분 크롤러

fatsecret.kr에서 식품명을 검색해 칼로리·영양소 요약과 서빙 사이즈별 칼로리를 조회하고, Tkinter GUI로 보여주고, 결과를 CSV로 저장하는 미니 프로젝트입니다.

2026-08-21 작성 · 2026-09-18 업데이트 Python · urllib · BeautifulSoup · pandas · tkinter 대상: fatsecret.kr

개요

식품명을 입력하면 fatsecret.kr의 검색 결과에서 후보 목록을 가져오고, 그중 하나를 선택하면 해당 식품의 칼로리·지방·탄수화물·단백질과 서빙 사이즈별 칼로리를 상세 페이지에서 읽어와 화면에 표시합니다. 조회한 결과는 버튼 클릭 한 번으로 CSV 파일로 저장할 수 있습니다.

크롤링 로직(fatsecret_food_data.py)과 화면 로직(fatsecret_food_ui.py)을 파일 단위로 분리해서, 데이터를 어떻게 가져오는지와 화면에 어떻게 보여주는지가 서로 섞이지 않도록 했습니다.

날씨 검색 위젯 weather.naver.com

fatsecret.kr 현재 버전
검색·상세 모두 정적 HTML로 렌더링되어 별도 API 없이 BeautifulSoup만으로 파싱 가능. 다만 한글 페이지에는 나트륨·당류 등 전체 영양표가 아닌 칼로리·지방·탄수화물·단백질만 노출됨을 확인.

크롤링 모듈 — fatsecret_food_data.py

0. _fetch_html(url) — HTTP 요청 수정됨

페이지 HTML을 받아오는 공통 함수입니다. 초기 버전에는 User-Agent 헤더 없이 urlopen(url)로 요청하고 응답 객체를 디코딩 없이 그대로 BeautifulSoup에 넘기는 문제가 있었습니다. 인코딩을 명시하지 않으면 파서가 문자 인코딩을 잘못 추정해 한글이 깨질 수 있고, User-Agent가 없으면 서버가 요청을 차단할 위험도 있어 아래처럼 HEADERS를 실어 보내고 utf-8로 명시적으로 디코딩하도록 고쳤습니다.

def _fetch_html(url):
    try:
        req = request.Request(url, headers=HEADERS)
        return request.urlopen(req, timeout=5).read().decode('utf-8')
    except error.URLError as e:
        raise ConnectionError(f'fatsecret.kr 접속에 실패했습니다: {e}')

1. search_food(keyword) — 검색

검색 결과 페이지의 table.searchResult 각 행에서 식품명, 브랜드, 상세페이지 경로를 뽑아 리스트로 반환합니다. 결과가 없으면 ValueError를 발생시켜 UI가 "검색 결과 없음"을 안내하도록 합니다.

def search_food(keyword, count=10):
    url = f'{BASE_URL}{SEARCH_PATH}?q={parse.quote(keyword)}'
    html = _fetch_html(url)
    soup = BeautifulSoup(html, 'html.parser')

    rows = soup.select('table.searchResult tr')
    if not rows:
        raise ValueError(f"'{keyword}'에 대한 검색 결과가 없습니다.")

    results = []
    for row in rows[:count]:
        name_a = row.select_one('a.prominent')
        if name_a is None:
            continue
        brand_a = row.select_one('a.brand')
        results.append({
            'name': name_a.get_text(strip=True),
            'brand': brand_a.get_text(strip=True) if brand_a else None,
            'detail_path': name_a['href'],
        })
    return results

2. get_food_detail(food_item) — 상세 조회

상세 페이지의 div.factPanel 표에서 칼로리·지방·탄수화물·단백질을 읽고, "서빙크기" 표에서 서빙 단위별 칼로리를 읽습니다. 표 구조가 바뀌어 factPanel을 찾지 못하면 RuntimeError로 구조 변경을 알립니다.

def get_food_detail(food_item):
    url = f"{BASE_URL}{food_item['detail_path']}"
    html = _fetch_html(url)
    soup = BeautifulSoup(html, 'html.parser')

    fact_table = soup.select_one('div.factPanel table.generic')
    if fact_table is None:
        raise RuntimeError('상세페이지 구조가 변경되어 영양정보를 찾을 수 없습니다.')

    facts = {}
    for td in fact_table.select('td.fact'):
        title = td.select_one('.factTitle')
        value = td.select_one('.factValue')
        if title and value:
            facts[title.get_text(strip=True)] = value.get_text(strip=True)
